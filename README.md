# AI Agent

A Python-based AI agent framework for building intelligent systems.

## Features

- Modular agent architecture
- LLM integration support
- Tool calling capabilities
- Memory management
- Async/await support

## Getting Started

### Prerequisites

- Python 3.9+
- pip or poetry

### Installation

```bash
pip install -r requirements.txt
```

### Running the Agent

```bash
python -m agent.main
```
